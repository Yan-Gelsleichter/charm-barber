# Instruções do Projeto

## Idioma e comunicação
- Sempre responda em português.
- O nível técnico do usuário é iniciante: ele não sabe programar. Antes de aplicar qualquer mudança, explique de forma simples o que será feito e por quê.
- Sempre avise antes de rodar comandos ou alterar arquivos importantes, e espere confirmação.

## Sobre o projeto
Este é um app de agendamento para barbearias (multi-tenant), chamado **Charme Barber / Barber Connect**.

- **Backend/dados:** Supabase.
- **Pagamentos:** integração com Mercado Pago (Checkout Pro).
- **Futuro:** integração com n8n para criar um agente de IA individual para cada barbearia conectada.
- **Plataformas:** o app roda na web e também precisa estar disponível na Play Store para Android.
